# Skills

Skills for designers and builders who care about the details.

## Install

    npx skills@latest add BrettfromDJ/skills

Or copy a skill folder from `skills/` into `~/.claude/skills/` (just for you) or `.claude/skills/` in a project (for everyone working on it).

## Why use it?

Agents write text that wraps badly. A heading ends on one lonely word. A paragraph trails off with "of CSS." on its own line. A card title splits into one long line and one stub. Each one is small, but together they make a product look unfinished.

These skills catch the details that make an interface feel designed rather than generated, and fix them across your whole product.

## Reference

- **pretty-text-wrap**: Finds and fixes bad line breaks everywhere in your product. It covers widows, stubby last lines and lopsided headings, using `text-wrap: balance` and `text-wrap: pretty` plus the edge cases they miss. It also measures the result at every screen width in Chrome and Safari.
